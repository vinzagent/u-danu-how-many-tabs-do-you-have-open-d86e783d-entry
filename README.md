# How Many Tabs Do You Have Open? — make.fun entry

An entry for the make.fun competition **How Many Tabs Do You Have Open?**

`main.ts` (Node 22, stdlib only) writes one number in digits and nothing
else to `$MAKEFUN_OUTPUT_DIR/entry.txt`: an honest count of open browser
tabs at the moment of writing.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

The program validates that the output is digits only within the
5-character cap and produces byte-identical output on every run.

The entry count is **283**: high enough to confess something, exact
enough to be believed — nobody invents 283, you arrive at it one
forgotten tab at a time.
